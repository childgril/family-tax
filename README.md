# 家族綜合所得稅試算系統

> 一個純前端、零後端、零安裝的台灣綜所稅多戶試算工具。為大家庭設計,支援多名納稅人、多種租賃情境、標準/列舉扣除額自動比較,以及歷年紀錄。

## 功能

- **儀表板** — 全家當年度應納稅總額、實際稅率、節稅總額一覽
- **家庭成員管理** — 支援夫妻、子女、扶養親屬、70歲長輩、身心障礙、需長照、在學等身分標記
- **出租物件管理** — 四種類型獨立計算:
  - 一般出租 (43% 必要費用)
  - 公益出租人 (每月免稅 15,000、超出部分費用 60%)
  - 包租代管 (與公益出租人相同優惠)
  - 免稅紀錄 (自住、無償提供親屬等,不計入所得但保留紀錄)
- **年度試算** — 每個申報戶獨立輸入薪資/利息/股利/其他所得,租金自動從物件帶入
- **扣除額自動比較** — 標準扣除額 vs 列舉扣除額自動算給你看,並推薦較划算者
- **歷年紀錄** — 以「成員」為主軸,看每個人歷年所得變化與所屬申報戶
- **多年度切換** — 內建 112、113、114 年度稅率與扣除額參數
- **資料管理** — 全部資料只存在你的瀏覽器,可匯出/匯入 JSON 檔備份

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository (例: `family-tax`)
2. 把 `index.html` 上傳到 repo 根目錄
3. 進入 `Settings` → `Pages` → `Source` 選擇 `Deploy from a branch`,Branch 選 `main` / `(root)`
4. 等 1-2 分鐘,網址會出現在 `https://<你的帳號>.github.io/family-tax/`
5. 直接開網址就能用,所有資料存在你自己的瀏覽器,不會傳到任何伺服器

> 想本機試,直接雙擊 `index.html` 用瀏覽器打開即可。

## 使用流程

1. 第一次進入 → 進入「資料管理」按「載入範例家庭」看七人家庭範例,或直接從頭建立
2. 「家庭成員」建立所有家族成員 (本人、配偶、子女、長輩等)
3. 「出租物件」一一登錄家裡所有出租房子 (包含免稅自住的)
4. 「本年度試算」建立申報戶 → 選主納稅人 / 配偶 / 扶養親屬 → 輸入各人所得 → 輸入列舉扣除額金額
5. 系統自動算出應納稅額,並比較標準 vs 列舉哪個划算
6. 「資料管理」定期匯出 JSON 備份 (重要!)

## 計算依據

- 財政部公告的各年度免稅額、扣除額、稅率級距
- 所得稅法第 14 條 (租賃所得)、第 17 條 (扣除額) 相關規定
- 公益出租人優惠 (住宅法第 23 條)、包租代管優惠
- 基本生活費差額條款 (納稅者權利保護法)

> **免責聲明**:本系統為自用試算工具,計算結果僅供參考,實際應納稅額以財政部國稅局核定為準。系統暫未實作:股利所得 28% 分開計稅、海外所得、所得基本稅額條例 (最低稅負制) 等特殊情境。

## 隱私

- **零後端**:純靜態網頁,沒有任何資料傳輸
- **本機儲存**:資料只存在你的瀏覽器 `localStorage`
- **清瀏覽器資料 = 資料消失**:請定期匯出 JSON 備份!
- **跨裝置**:匯出 JSON 檔,在另一台裝置匯入即可

## 技術

- 單一 HTML 檔,內含 React 18 + Tailwind CSS + Babel (透過 CDN)
- 不需要 build,不需要 node_modules,直接用瀏覽器打開
- 想離線使用?把 React/Tailwind/Babel 三個 CDN 改成本機檔即可
